# Основные идеи многопоточки

## Процесс VS Поток
* Процесс - это самоятельный, атомарный элемент операционной системы.
Он не делится памятью с другими процессами, взаимодействие между ними затруднено. 
Напр, это наш браузер, ide, наше приложение.
Процесс имеет несколько потоков.
* Поток - это элемент процесса, который может пользоваться общей памятью внутри процесса.
Есть возможность взаимодействия с другими потоками этого процесса.

## Как создать новый поток?
* Способ 1. Отнаследоваться от Thread, переопределить метод run(), запустить метод start().
* Способ 2. Реализовать интерфейс Runnable, передать его в конструктор Thread и запустить его start().
* Способ 3. Сразу передать лямбду в конструктор Thread и запустить его start().

## Как затормозить поток на время?
Thread.sleep(1000)

## Как дождаться другой поток?
.join()

## Синхронизация
* Может быть реализована через `synchronized`:
```
    syncronized (objectMonitor) {
            // your specific logic
            }
```
В такой блок кода может зайти только один поток одновременно (по этому objectMonitor).

## Data Race
Имеем ввиду, что порядок выполнения операций в потоках без синхронизации не гарантирован. 
Вывод может разным от запуска к запуску.
